Cholera remains a longstanding endemic pathogen affecting much of sub-Saharan Africa, making accurate disease surveillance over time and across countries a critical asset for modeling disease dynamics and planning public health responses. However, existing surveillance databases—while thorough—capture only 52.5% of country-months across the WHO African Region (1970-present), significantly impairing efforts to fit models over endemic time scales and predict future outbreaks.

This project deploys a sophisticated 7-agent AI orchestration system powered by Anthropic's flagship Opus 4.1 LLM to systematically fill these critical surveillance gaps. Building upon baseline data from the JHU Cholera Taxonomy Repository (comprehensive 1970-2020+ historical coverage) and the WHO AWD Dashboard (recent 2023-2025 surveillance), our workflow orchestrator manages seven specialized agents with human supervision. These agents execute parallel batch searches across 486+ pre-authorized sources, validate zero-transmission periods crucial for model calibration, expand geographic granularity to sub-national levels, and apply rigorous 4-stage quality validation protocols to ensure data integrity.

Each country undergoes upwards of 1,000 targeted queries with data observation yield-based stopping criteria, ensuring thorough yet efficient search coverage. Early implementations demonstrate substantial improvements to baseline data (Angola's pilot study enhanced coverage from 59.4% to 75%). These enhanced surveillance data are intended to support transmission dynamics modeling within the MOSAIC framework, enabling more accurate endemic cholera predictions and evidence-based intervention planning across 40 countries in the WHO African Region.

Important Note: While this project is open source, it remains an experimental pilot study and the AI-generated data have not yet been fully validated by human experts. Data posted here will change over time as we refine methods. All data should be independently verified before use.

AI-Enhanced Data Mining Methods

1. Gap Analysis and Baseline Integration

The workflow initiates with systematic integration of two foundational databases: the JHU Cholera Taxonomy Repository (1970-2020+ historical coverage) and the WHO AWD Dashboard (2023-2025 recent surveillance). These baselines are analyzed using automated gap detection algorithms that identify missing surveillance periods at monthly resolution. The analysis revealed 47.5% missing data across 40 MOSAIC framework countries, with gaps ranging from complete absence (5 countries with 0% coverage) to partial surveillance interruptions during conflict periods or health system disruptions.

2. Seven-Agent Orchestration Architecture

Our system deploys seven specialized AI agents managed by a master orchestrator powered by Anthropic's Opus 4.1 LLM. Each agent executes specific functions within the data enhancement pipeline:

  • Agent 1 (Baseline Collector): Systematically mines 486+ pre-authorized sources using parallel batch processing (20 queries per batch)
  • Agent 2 (Geographic Expansion): Drills down from national to provincial and district-level surveillance data
  • Agent 3 (Zero-Transmission Validator): Confirms cholera-free periods essential for accurate model calibration
  • Agent 4 (Obscure Source Explorer): Recovers data from archives, gray literature, and broken links using specialized techniques
  • Agent 5 (Cross-Reference Integrator): Resolves conflicts between sources and synthesizes partial reports
  • Agent 6 (Gap Context Investigator): Distinguishes between surveillance failures and true disease absence
  • Agent 7 (Quality Auditor): Performs final validation and generates comprehensive quality reports

3. Search Protocol and Stopping Criteria

Agents execute targeted searches using data observation yield-based stopping criteria: continuing until three consecutive batches achieve <5% yield or reaching 10 total batches (200 queries maximum per agent). This empirically-validated approach balances thoroughness with computational efficiency. Search queries are specifically constructed to target identified temporal gaps, with enhanced contextual targeting based on seasonal patterns, outbreak scales, and geographic specificity.

4. Quality Validation Framework

All discovered data undergo rigorous 4-stage validation:

  • Stage 1: Source authentication and institutional verification
  • Stage 2: Epidemiological plausibility checks (CFR 0.1-15%, outbreak duration validation)
  • Stage 3: Cross-reference confirmation for outbreaks >1000 cases
  • Stage 4: Duplication detection and temporal alignment

Sources are classified into four reliability tiers with confidence weights:

Tier Source Type Examples Confidence Weight
Tier 1 Official/Government WHO, Ministry of Health, Government Statistics 0.9 - 1.0
Tier 2 UN/Academic UNICEF, OCHA, Peer-reviewed journals 0.7 - 0.9
Tier 3 News/NGO ReliefWeb, MSF, Regional news 0.3 - 0.6
Tier 4 Local/Unofficial Local media, Social reports, Preliminary data 0.1 - 0.3

5. Output Standardization and Integration

Enhanced data follows strict formatting standards compatible with existing epidemiological databases. Geographic coding uses hierarchical identifiers (AFR::{ISO}::{PROVINCE}::{DISTRICT}), temporal data employs ISO 8601 date formatting, and all observations include dual-reference indexing for complete source traceability. The system produces three core outputs per country: cholera_data_ai.csv (surveillance observations), metadata_ai.csv (source documentation), and search_report.txt (quality metrics and gap analysis).

Agent 0 Workflow Orchestrator

The Workflow Orchestrator serves as the master coordination system for the entire cholera surveillance enhancement pipeline. Powered by Anthropic's Opus 4.1 LLM, this autonomous agent manages the sequential deployment of seven specialized sub-agents, monitors their progress in real-time, and ensures comprehensive data collection while maintaining quality standards. The orchestrator initializes each country's workflow by establishing the file structure, loading baseline gap analysis data, and configuring agent-specific parameters based on the country's surveillance profile. Throughout execution, it tracks data observation yields, enforces stopping criteria, handles memory optimization through context compression, and automatically updates the project dashboard at critical milestones. While designed for autonomous operation, the orchestrator's sophisticated state management ensures workflow continuity across extended processing sessions, though in practice human intervention is currently required to initiate and monitor the workflow for each country to ensure data quality and handle edge cases.

Agent 1 Baseline Collector

The Baseline Collector establishes the foundational dataset by executing systematic searches across 486+ pre-authorized institutional sources. This agent prioritizes high-reliability sources including WHO Disease Outbreak News, Weekly Epidemiological Records, UNICEF humanitarian situation reports, and Médecins Sans Frontières field reports. Operating with parallel batch processing (20 queries per batch), it targets identified surveillance gaps from the baseline analysis while maintaining comprehensive coverage across all time periods. The agent employs sophisticated query construction techniques, combining temporal constraints, geographic specificity, and contextual keywords to maximize data discovery rates. Its stopping criteria—continuing until three consecutive batches achieve less than 5% data observation yield or reaching 10 total batches—ensures thorough coverage while preventing inefficient over-searching. The Baseline Collector typically discovers 20-40 new surveillance observations per country, forming the critical foundation upon which subsequent agents build.

Agent 2 Geographic Expansion Specialist

The Geographic Expansion Specialist transforms national-level surveillance data into granular sub-national coverage essential for accurate spatial modeling. This agent systematically drills down administrative hierarchies, searching for provincial health department reports, district surveillance bulletins, and municipal health system updates that provide location-specific outbreak details. By targeting regional WHO offices, provincial ministries of health, and district health information systems, it expands the geographic resolution of cholera data from country-level aggregates to specific provinces, districts, and municipalities. The agent employs location-aware query strategies, incorporating local administrative names, regional languages, and geographic identifiers to discover surveillance data that national-level searches might miss. This geographic granularity proves particularly valuable for understanding transmission patterns, identifying outbreak hotspots, and calibrating spatial components of epidemiological models.

Agent 3 Zero-Transmission Validator

The Zero-Transmission Validator addresses a critical but often overlooked aspect of disease surveillance: confirming and documenting cholera-free periods. Rather than treating data absence as missing information, this agent actively searches for evidence that validates periods of zero cholera transmission, which are essential for accurate model calibration and understanding of disease dynamics. It distinguishes between surveillance system failures (where reporting infrastructure collapsed) and true disease absence (where functional surveillance systems reported no cases). The agent examines health system functionality reports, cross-border transmission patterns, and explicit "no cases reported" statements from WHO and government sources. By creating validated zero-transmission observations in the enhanced dataset, this agent enables models to accurately capture the intermittent nature of cholera transmission, improving predictions of outbreak timing and disease re-emergence patterns.

Agent 4 Obscure Source Explorer

The Obscure Source Explorer ventures beyond conventional databases to recover cholera surveillance data from unconventional, historical, and hard-to-access sources. This agent specializes in mining gray literature, institutional archives, colonial medical records, missionary health reports, and pre-digital surveillance documentation that standard searches typically miss. It employs advanced recovery techniques including Internet Archive queries for broken links, alternative language searches in local vernacular, and deep exploration of university repositories and digitized historical collections. The agent particularly excels at filling historical gaps (pre-2000) and long-duration surveillance interruptions (≥3 years) where conventional sources provide limited coverage. By recovering data from French colonial health bulletins, Portuguese missionary records, and regional academic theses, this agent often discovers unique surveillance observations that significantly extend the temporal range of available data.

Agent 5 Cross-Reference Integrator

The Cross-Reference Integrator performs sophisticated source triangulation and data synthesis to maximize information extraction from discovered sources while ensuring consistency and accuracy. This agent re-examines successful sources for adjacent time periods and geographic areas, follows citation networks to discover derivative reports, and identifies relationships between partial sources that can be combined into complete outbreak records. When encountering conflicting information—such as different case counts for the same outbreak—it applies established resolution protocols based on source reliability, temporal proximity, and epidemiological plausibility. The agent excels at expanding single successful discoveries into comprehensive datasets by systematically exploring related documentation, annual reports from the same institutions, and cross-referenced publications. Through this iterative refinement process, it typically increases data yield from confirmed sources by 30-50%, while simultaneously improving confidence through multi-source validation.

Agent 6 Gap Context Investigator

The Gap Context Investigator provides critical intelligence about remaining surveillance gaps by investigating why certain periods lack cholera data despite extensive searching by previous agents. This agent examines the broader context surrounding temporal gaps of six months or longer, analyzing factors such as health system functionality, political stability, conflict timelines, natural disasters, and changes in disease reporting protocols. Rather than simply marking periods as "missing data," it classifies gaps into distinct categories: surveillance system collapse (where infrastructure failed), reporting interruption (where data exists but remains inaccessible), or validated absence (where functional systems confirmed no cholera). The agent searches for health system assessments, conflict impact evaluations, and retrospective analyses that explain data gaps, providing essential metadata that informs how models should handle missing periods.

Agent 7 Quality Auditor

The Quality Auditor serves as the final checkpoint in the data enhancement pipeline, conducting comprehensive validation of the entire enhanced dataset while generating detailed documentation of the workflow's achievements. This agent performs multi-stage quality control including CSV format validation to prevent dashboard integration failures, epidemiological plausibility checks across all observations, temporal consistency verification, and geographic coding standardization. It calculates key metrics including gap-filling success rates, coverage improvements from baseline, geographic expansion achievements, and source diversity indices. The agent produces a concise executive summary documenting total sources discovered, data observations added, critical gaps filled, and remaining limitations. By comparing the enhanced dataset against the original baseline gaps, it provides quantitative assessment of the workflow's effectiveness. The Quality Auditor ensures that all outputs meet rigorous standards for integration into the MOSAIC epidemiological modeling framework.
