MOSAIC Subagent Configurations

This directory contains the configuration files needed to create specialized subagents for the MOSAIC cholera surveillance data enhancement workflow using Claude Code's Task tool with specialized subagent types.

Overview

The MOSAIC workflow uses a sophisticated multi-agent architecture with specialized AI agents, each operating through Claude Code's subagent system with purpose-built system prompts and specific expertise areas.

Agent Configuration Files

Workflow Orchestrator

  • agent_0_workflow_orchestrator.md - Master Workflow Orchestrator

    • - Coordinates the complete 6-agent cholera data enhancement workflow

    - Uses country-specific prompt files (data/{ISO}/prompt_{ISO}.txt) for execution

    - Manages sequential agent invocation with appropriate subagent types

Core Data Collection Agents

  • agent_1_baseline_collector.md - Baseline Data Collector (subagent_type: cholera-baseline-collector)

    • - Systematic priority source coverage and foundational searches

    - Batch-based stopping criteria with data observation yield tracking (minimum 5 batches)

    - Focuses on WHO, government, and high-priority institutional sources

  • agent_2_geographic_expansion.md - Geographic Expansion Specialist (subagent_type: geographic-expansion-specialist)

    • - Provincial/district-level data discovery and subnational mining

    - Administrative hierarchy drilling with geographic-level targeting

    - Expands coverage to sub-national administrative levels

  • agent_3_zero_transmission.md - Zero-Transmission Validator (subagent_type: zero-transmission-validator)

    • - MANDATORY: Documents validated absence periods as data observations in cholera_data_ai.csv

    - Regional cross-validation with neighboring countries for cholera-free periods

    - Systematic validation of gaps between documented outbreaks

  • agent_4_obscure_sources.md - Obscure Source Explorer (subagent_type: obscure-source-explorer)

    • - Alternative source discovery beyond standard databases and suggested sources

    - Historical archives, gray literature, and unconventional source exploration

    - Recovery of data from broken/inaccessible sources

  • agent_5_cross_reference.md - Cross-Reference Integrator (subagent_type: cross-reference-integrator)

    • - Cross-validation and conflict resolution between sources

    - Citation network expansion and reference following

    - Comprehensive source triangulation and data synthesis

  • agent_6_quality_auditor.md - Quality Auditor (subagent_type: cholera-quality-auditor)

    • - Comprehensive quality validation and gap coverage assessment

    - Final report generation and dataset finalization

    - Enhanced Gap Impact Analysis: Pre/post workflow coverage comparison

Implementation Process

Step 1: Initial Setup

Run the main setup script to initialize all countries and baseline data:

``bash

./setup.sh # Automatically configures all 40 MOSAIC countries

`

This setup script:

  • Creates directories for all 40 MOSAIC framework countries
  • Integrates JHU cholera database as baseline data
  • Integrates WHO dashboard surveillance data
  • Generates country-specific prompt files (data/{ISO}/prompt_{ISO}.txt)
  • Prepares gap analysis and reference files

Step 2: Subagent Access via Task Tool

Use the Task tool with appropriate subagent_type parameters to access specialized agents:

`python

Example usage in Claude Code:

Task(description="Ethiopia baseline collection",

prompt="ETH", # Uses data/ETH/prompt_ETH.txt

subagent_type="workflow-orchestrator")

Or directly invoke specific agents:

Task(description="Agent 1 baseline collection",

prompt=agent_1_instructions,

subagent_type="cholera-baseline-collector")

`

Step 3: Workflow Execution

The workflow orchestrator agent manages the complete 6-agent sequence:

  1. Agent 1: Baseline data collection using cholera-baseline-collector
  2. Agent 2: Geographic expansion using geographic-expansion-specialist
  3. Agent 3: Zero-transmission validation using zero-transmission-validator
  4. Agent 4: Obscure source exploration using obscure-source-explorer
  5. Agent 5: Cross-reference integration using cross-reference-integrator
  6. Agent 6: Quality audit using cholera-quality-auditor

Step 4: Progress Tracking

Monitor progress using the automated dashboard system:

`bash

bash update_dashboard.sh # Updates completion status and visualization

`

Architecture Benefits

Technical Advantages

  • Separate Context Windows: Each agent maintains independent context, preventing bloat
  • Specialized Expertise: Purpose-built system prompts optimized for specific tasks
  • Parallel Processing: Multiple agents can operate simultaneously
  • Error Isolation: Issues in one agent don't cascade to others
  • Scalable Design: Reusable agents across all 40 MOSAIC countries

Operational Benefits

  • Maintained Convenience: Single-command execution per country preserved
  • Automated Parameters: Country-specific context generated automatically
  • Quality Assurance: Specialized validation and quality control agent
  • Performance Tracking: Built-in stopping criteria and yield monitoring
  • Complete Documentation: Comprehensive logging and reporting

Workflow Execution Pattern

`

│ ├─ Agent 1: Baseline Data Collector (cholera-baseline-collector)

Integration with MOSAIC Framework

Data Sources Integration

  • JHU Historical Database: Baseline coverage (1970-2020+)
  • WHO Dashboard Surveillance: Recent data (2023-2025)
  • AI Agent Discoveries: Gap-filling enhancements

Quality Standards

  • 4-Tier Source Reliability: Level 1 (WHO/Government) to Level 4 (Local media)
  • Dual-Reference Indexing: Sequential integers ↔ exact source names
  • Confidence Weighting: Quality-based modeling weights (0.1-1.0)
  • Zero-Transmission Documentation: Absence periods as data observations

Output Standards

  • Enhanced cholera_data_ai.csv: AI discoveries with source_database: 'AI'
  • Complete metadata_ai.csv: Full source documentation and validation
  • Search logs: Individual agent activity logs (search_log_agent_X.txt)
  • Quality report: Executive summary (search_report.txt, created by Agent 6)
