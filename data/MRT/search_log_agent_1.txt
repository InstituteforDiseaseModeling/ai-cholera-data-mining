WHAT MADE THIS RUN WORK - REUSABLE FOR OTHER COUNTRIES:
  The WHO Weekly Epidemiological Record annual "Cholera in {YEAR}" country tables
  are complete in WHO IRIS from 1970 onward and settle the question that WHO GHO
  cannot: GHO simply omits zero-report years, so GHO silence is ambiguous, whereas
  the WER table is an enumeration and a country's absence from it is a notified
  zero. WebFetch on iris.who.int returns HTTP 403. The access route that works is:
    curl -A "<browser UA>" https://iris.who.int/server/api/discover/search/objects?query="CHOLERA IN 1980"
    -> item uuid -> /server/api/core/items/{uuid}/bundles -> bitstreams -> /content
    -> pdftotext -layout -> grep the Africa table
  Always run the positive control (batch 7) before trusting absence from a table.
