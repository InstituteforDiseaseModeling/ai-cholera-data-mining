CAPABILITY UNLOCK - hand this to every future agent, any country
--------------------------------------------------------------------------------
Agent 4 established that WER must be read from the ORIGINAL-bundle PDF with
`pdftotext -layout` rather than the IRIS TEXT bitstream. That is necessary but
NOT sufficient. The WER "Diseases Subject to the Regulations" table is a 3-4
column newspaper layout, and -layout interleaves those physical columns: a
number from the Philippines column lands on the Nigeria row. Worse, the table
uses a BRACE that joins two value lines (confirmed, then suspected) to one state
label, and -layout destroys the brace, so a two-line state reads as two
unlabelled rows.

Two tools fix it, both in /tmp/nga5:
  col.py    - parses `pdftotext -bbox-layout` XML and re-renders ONE physical
              column at a time, selected by x-coordinate. Columns stay intact.
  nig2.py   - fuzzy-matches the OCR-mangled country label ('JIGERIA', 'NIGERLA',
              'N1GERIA'), requires a date-range token or >=3 numbers nearby, and
              emits a 300dpi PNG crop of the block via
              `pdftoppm -r 300 -x -y -W -H`.
The PNG is then read directly. That is the only way to see the brace.

HOW TO READ THE TABLE, stated once so nobody re-derives it:
  C = cases, D = deaths. Suffix s = SUSPECTED, r = REVISED, p = preliminary,
  i = imported (the key is printed at the head of every notifications table).
  A brace joining two VALUE lines to one state label means the state reported
  both confirmed and suspected in that week; the week's total is their SUM.
  A brace joining several LABEL lines to one value line means those divisions
  were reported together.

*** THE SUMMING RULE IS PROVEN, NOT ASSUMED ***
  WER 1973;48(43) p.414 prints Nigeria's six four-weekly national totals for
  1973: 123, 138, 87, 218, 88, 65 (printed sum 719). Summing the WEEKLY state
  figures extracted here, with the suspected line added to the confirmed line,
  reproduces every one of those six numbers EXACTLY:
     P1 31.XII-27.I   29 + 24 + 35 + 35              = 123
     P2 28.I-24.II    21 + 47 + 52 + 18              = 138
     P3 25.II-24.III  27 + 31 + [0] + 29             =  87
     P4 25.III-21.IV  123 + 39 + 32 + 24             = 218
     P5 22.IV-19.V    22 + 30 + 27 + 9               =  88
     P6 20.V-16.VI    19 + 13 + 12 + 21              =  65
  Two of those weeks were PREDICTED BEFORE BEING FOUND. Period 4 needed a

A DELIBERATE DECISION NOT TO WRITE NATIONAL WEEKLY ROWS - reasoning recorded
--------------------------------------------------------------------------------
The weekly state figures sum to a clean national weekly series for 1972-73, and
the temptation to enter it is strong. I did not, for two reasons that a future
agent should weigh rather than re-derive:

 1. IT WOULD HAVE NO DOWNSTREAM EFFECT. py/build_weekly_timeseries.py sets
    SOURCE_PRIORITY = {"WHO":3, "JHU":2, "AI":1} and processes sources in
    ascending priority so the higher one writes last. JHU carries a national
    ANNUAL row for both 1972 and 1973; it is Fourier-disaggregated across all 52
    weeks and overwrites every AI national weekly value for those years. The
    rows would be invisible to the only consumer that reads national rows.
 2. IT WOULD MAKE THE FILE SELF-CONTRADICTORY. For 1973 the weekly series
    reaches 719 by 16 June against a JHU/GHO annual of 157 - the unresolved
    WER-vs-GHO conflict Agent 4 documented. Writing national weeklies would
    embed that conflict as data instead of leaving it as an open question.
    See the CONFLICT RESOLUTION section for what the weekly data does say
    about it.

So: sub-national rows only. Historical states that map to exactly one modern
ADM1 get that ADM1 (Lagos; Calabar Prov -> Cross_River; Ibadan Prov -> Oyo;
Abeokuta Prov -> Ogun). The 1967-76 multi-state units go to Multi_State, and
where SEVERAL of them reported in the same week they are carried as ONE row with
the per-state breakdown quoted in processing_notes - deliberately, because
several Multi_State rows on the same (location, period) key is precisely the
artefact that produced five of the 27 same_period_conflict warnings this agent
was sent to clear.

2. READING WER TABLES: THE THREE THINGS THAT COST ROWS.
   a. pdftotext -layout interleaves WER's 3-4 newspaper columns; a number from
      the Philippines column lands on the Nigeria row. Fix: bbox-coordinate
      single-column re-render (/tmp/nga5/col.py) or a page-image crop.
   b. The BRACE is invisible to every text extractor. Two value lines braced to
      one state label means confirmed then suspected FOR THE SAME WEEK, and the
      week total is their sum. Several rows in this file were the first line
      only. Several others were the second line only.
   c. ALWAYS read the disease heading positionally - same physical column, above
      the country label. In ten volumes this run rejected Nigerian YELLOW FEVER
      (twice), POLIOMYELITIS, MENINGOCOCCAL MENINGITIS, DIPHTHERIA and a
      multi-disease annual table, every one of which was within a few lines of a
      genuine cholera block.

3. WHEN IS A WER COUNTRY LINE ADMISSIBLE AFTER 1974? Use arithmetic, not era.
   A WER notification figure is admissible when it RECONCILES with an
   independently published cumulative or annual for the same country-year, and
   inadmissible when it does not. Nigeria 1996 passes to the unit on two
   variables (7 130 + 5 244 = 12 374; 561 + 632 = 1 193, and 12 374 is the
   annual). Nigeria 1992 fails by a factor of 54 and contradicts itself between
   two issues. Nigeria 1975-76 contradicts itself within one page. The test is
   cheap and checkable; judging by era is not.

4. AFTER 1974, WER'S SUB-NATIONAL CHANNEL IS THE INFECTED-AREA DECLARATION, NOT
   THE CASE TABLE. "Newly infected areas as at <date>" and "Infected areas as at
   <date>" name administrative units with no counts - presence evidence, which
   belongs in cholera_presence_ai.csv. For Nigeria 1991 this turned one
   undifferentiated national row into a dated 21-state footprint.
   CAVEAT THAT GENERALISES: check the declaration against the country's
   administrative history. Nigeria's 1992-96 COMPLETE lists still name Bendel and
   Gongola States, abolished in August 1991, so they are carried-forward legacy
   lists and were rejected; the "newly infected" declarations use current names
   and were accepted.

5. RELIEFWEB: THE API IS SHUT, THE WEBSITE IS NOT. api.reliefweb.int v1 returns
   410 and v2 returns 403 for every appname - the appname is issued by ReliefWeb
   staff against a human registration form and cannot be obtained by an agent.
   reliefweb.int itself returns 200 and its search pages are parseable:
       https://reliefweb.int/updates?search=<url-encoded terms>
   That route produced 41 of this agent's rows, including a complete 37-state
   Nigerian enumeration for 2025 and the state-EOC figure a previous agent had
   judged unobtainable. Use it for every country until somebody registers an
   appname.
