source_index 293 (WHO Nigeria end-of-outbreak declaration, 21 January 2019).

WHY NOT MOVED TO ./data/NGA/cholera_presence_ai.csv.  That file is defined by
CLAUDE.md, and by py/add_observation.py cmd_add_presence, as "cholera confirmed
PRESENT but no count available"; its evidence column is hardcoded to the single

would assert cholera presence in Borno across precisely the window in which WHO
and the three State Commissioners for Health declared the outbreak over.  That

keeping the row or deleting it.  The binary the brief offered is a false one.

applied was active laboratory surveillance returning negatives over two
incubation periods; and the accessible majority of Borno - including Maiduguri
Metropolitan, the epicentre of the 2018 epidemic - genuinely recorded no cases.
Deleting it discards a true observation.

WHY THE LABEL WAS DEMOTED.  Agent 6's scope caveat existed only as prose, and
no consumer reads prose.  py/build_weekly_timeseries.py takes its only
machine-readable handle on a zero row from the first "Evidence type: X" token:
Documented_Absence is graded method=documented_zero at the row's stated
confidence, whereas Inferred_Absence is graded inferred_zero and hard-capped at
INFERRED_ZERO_MAX = 0.6.  A caveat that changes no field is the identical
defect class the brief raised in item 1 - a judgement recorded but not acted
on.  Demoting the token makes it operative.  Verified after the edit:
        canonical Evidence type token = inferred_absence

  Every table closes. There is no unattributed residual anywhere, so an

  single-case states, so the reporting threshold is 1, not a cutoff that would
  hide small outbreaks. The rows are weighted 0.8, not 1.0, and carry
  'surveillance status: partial'.

  WHAT WOULD FALSIFY IT - three concrete tests, in descending risk:
  1. THESE ARE ZEROS OF REPORTING, NOT OF TRANSMISSION. NCDC's table is built
     from state IDSR returns; a state that filed nothing is indistinguishable
     from a state that filed a zero. The falsifier is to find a state-year where
     a state MoH, WHO AFRO, MSF or a peer-reviewed study documents cholera in a
     state NCDC's table omits. This is not hypothetical: the SAME NCDC
     apparatus omitted 13,234 Borno line-listed cases from its national Weekly
     Epidemiological Report in 2026 (P1.3 above). If the routine stream can drop
     Borno nationally, it can drop a state sub-nationally.
  2. PERIOD OVER-EXTENSION, the weakest part. The NCDC cholera sitrep series was
     discontinued after Epi Week 9 of 2025; the 2025 zeros drawn from it are
     correctly capped at 2025-03-02. But the 22 rows from metadata 138 extend
     zeros to 2025-06-30 on a coarser Annual Report quarterly table. Falsifier:
     any Q2 2025 state-level cholera report from a non-NCDC source.
  3. SILENT PARSING FAILURE. A state whose name failed to parse becomes a zero
     by complement. This hazard is already documented in this dataset -
     'Cross River' wraps across two lines in several issues and parses as a bare
     'River'. Falsifier: re-read the rendered source text, not the parsed list,
